# PoE Filter Generator (PoE1 & PoE2)

เครื่องมือสร้าง **loot filter** สำหรับ Path of Exile 1 และ 2 แบบ standalone —
ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องลง Python

รองรับทั้ง **PoE1** และ **PoE2** สลับได้ในหน้าต่างเดียว มี 2 แท็บ:
**NeverSink** (ใช้ tier ของ NeverSink ตรงๆ) และ **Whitelist** (โชว์เฉพาะที่คุณเลือก ซ่อนที่เหลือ)

👉 **[ดาวน์โหลดตัวล่าสุด (PoE-Filter-Generator.exe)](https://github.com/foolshang/PoE-Filter-Generator/releases/latest/download/PoE-Filter-Generator.exe)**

หรือเข้าหน้า [Releases](https://github.com/foolshang/PoE-Filter-Generator/releases) เพื่อเลือกเวอร์ชัน

### ครั้งแรกที่รัน Windows อาจเตือน
ไฟล์ไม่ได้ sign ดิจิทัล → Windows SmartScreen จะขึ้น "Windows protected your PC"
กด **More info → Run anyway** ครั้งเดียว ครั้งต่อไปไม่ถามอีก

## ใช้ยังไง

1. เปิดโปรแกรม → เลือกภาค **PoE1 / PoE2** ด้านบน
2. เลือกแท็บ **NeverSink** หรือ **Whitelist** (อธิบายด้านล่าง) แล้วตั้งค่าที่ต้องการ
3. ตั้ง **Game folder** (เว้นว่าง = หาโฟลเดอร์เกมให้อัตโนมัติ)
4. ตั้ง **ชื่อ filter** (ค่าเริ่มต้น: แท็บ NeverSink = `poe-checker` · แท็บ Whitelist = `poe-checker-whitelist`
   ตั้งเองได้ มีหลายไฟล์ในโฟลเดอร์เดียวกันได้ไม่ทับกัน)
5. กด **Generate Now**
6. ในเกม: **Options → Game → เลือก filter แล้ว reload**

ค่าที่ตั้งจำไว้ให้เมื่อกด **Save Settings** หรือ Generate

## แท็บ NeverSink — ใช้ tier ของ NeverSink ตรงๆ

สร้าง filter จาก [NeverSink's Indepth Loot Filter](https://github.com/NeverSinkDev/NeverSink-Filter)
โดยไม่ใช้ราคาเลย — tier ทั้งหมดมาจากที่ NeverSink จัดไว้

- **Strictness** เลือกได้ 0–6 (Soft ถึง Uber-Plus-Strict)
- **เสียงแจ้งเตือน 6 ช่อง (เสียง 1 – 6)** — เลือกไฟล์เสียงของคุณเอง (mp3 / wav / ogg) ปุ่ม **Clear** = กลับไปใช้เสียงของ NeverSink
  แต่ละช่องผูกกับเลขเสียงของ NeverSink: **เสียง 1 = เสียง 6**, **เสียง 2 = เสียง 1**, **เสียง 3 = เสียง 2**, **เสียง 4 = เสียง 3**,
  **เสียง 5 = เสียง 4**, **เสียง 6 = เสียง 5** — ใส่ให้ **ทุก block** ที่ NeverSink ใช้เลขเสียงนั้น (ช่องว่าง = ไม่แตะ เสียงเดิมของ NeverSink ยังเล่น)
  โปรแกรมก๊อปไฟล์ไปไว้ในโฟลเดอร์ filter ให้ **ใช้ชื่อไฟล์เดิม** · เสียงของแท็บนี้ไม่ไปแท็บ Whitelist (ใช้ร่วมกันแค่เสียงของเควส Q)
- **ของเควส (Q)** — ของเควสโชว์เสมอทั้ง 2 แท็บ — ตั้งสไตล์ Q (สี เสียง) ได้ที่แท็บนี้ (ไม่ตั้ง = ใช้สไตล์ของ NeverSink)
- **Regenerate เมื่อ NeverSink อัปเดต** — ติ๊กไว้ แล้วเปิดโปรแกรมทีไรจะเช็ค NeverSink และสร้าง filter ใหม่ให้เมื่อมีเวอร์ชันใหม่
  (หรือกด **Refresh NeverSink Base** เพื่อดึงใหม่เอง)

## แท็บ Whitelist — โชว์เฉพาะที่เลือก ซ่อนที่เหลือทั้งหมด

ทุกอย่างอยู่ใน **tier S / A / B / C / D** — S / A / B / C = โชว์ (แต่ละ tier มีสไตล์ สี ขนาด ไอคอน ลำแสง เสียง
และจำนวนขั้นต่ำของตัวเอง; C ค่าเริ่มต้นดูจางกว่า B) · **D = ซ่อน**
**ค่าเริ่มต้นมาจาก NeverSink ระดับ 2 (Semi-Strict)**: t1–t2 = S, t3–t4 = A, t5–t6 = B, t7–t8 = C, ขั้นที่ NeverSink ซ่อน = D
(ladder ตัวอักษร s / a / b / c / d / e ของ PoE2 จับคู่ตามลำดับขั้น) แล้วคุณปรับเองได้ทีละชิ้น หรือทีละหมวด

> ไฟล์ / ค่าที่เก็บไว้จากรุ่นก่อน (ที่ C = ซ่อน) จะถูกแปลง C → D ครั้งเดียวตอนเปิด และแจ้งจำนวนใน Status;
> S / A / B ที่ตั้งไว้คงเดิม · เสียง S / A / B เดิมของแท็บ NeverSink ถูกแปลงเป็นเสียง 1 / 2 / 3 และเป็นเสียง tier S / A / B ของแท็บ Whitelist ชุดเดิม (ครั้งเดียว)

**วิธีใช้**
1. **เลือก tier** (S / A / B / C) ที่ต้องการก่อน
2. ตั้ง **สไตล์ของ tier** (สี ความทึบ ขนาด ไอคอน ลำแสง **เสียง**) — แสดงอยู่ในหน้าเลย ไม่เปิดหน้าต่างใหม่ ใช้ร่วมกันทุกไอเท็มใน tier นั้น
   เสียงของ tier S / A / B / C เป็นของแท็บ Whitelist เอง (ไม่เกี่ยวกับแท็บ NeverSink)
3. เลือก **หมวด** แล้วติ๊ก/เอาติ๊กไอเท็ม — ติ๊ก = ย้ายเข้า tier ที่เลือก เอาติ๊กออก = D (ซ่อน)
   หรือใช้ปุ่ม *ทั้งหมวด → tier นี้* / *ทั้งหมวด → D (ซ่อน)* / *รีเซ็ต* ได้
4. กด **Generate Now**

**หมวดที่มี**
- **ไอเท็มตามชื่อ** — Currency, Fragment, Rune, Essence, Omen, Catalyst, Scarab, Fossil, Div Card ฯลฯ
  (ตามเกม) รวมถึง Runegraft, Vial, Corpse, Wombgift, Relic
- **Unique** — ตั้ง tier ต่อ unique (ผูกกับ base) หรือทั้งหมวด
- **Tablet** (PoE2)
- **Flask / Charm** (PoE1: **Flask / Tincture**) — มี 2 แถว (Flask กับ Charm / Tincture) แต่ละแถวเลือกได้ 2 แบบ:
  - **ค่าเริ่มต้น** = block ของ NeverSink ทั้งหมดของแถวนั้น
  - **ตั้งค่าเอง** = มีช่อง Normal / Magic เลือก S / A / B / C / D (เริ่มที่ B ทุกช่อง) ช่องที่ตั้งชนะ block ของ NeverSink ·
    Unique ไปตั้งที่หมวด Unique · ตั้ง D = ซ่อนทุกชิ้นของ rarity นั้น รวมตัวที่ mod ดีด้วย
    เลือกกลับเป็น "ค่าเริ่มต้น" แล้วค่าที่ตั้งไว้ถูกจำไว้ (ไม่เขียนลงไฟล์) เผื่อกลับมาตั้งค่าเอง
- **อุปกรณ์ตาม class** — แถวละ 1 class จัดเป็นกลุ่ม อาวุธ (รวม Quivers) / เกราะ / เครื่องประดับ / อื่นๆ
  แต่ละแถวเลือก **ค่าเริ่มต้น** (block ของ NeverSink ทั้งหมด) หรือ **ตั้งค่าเอง** (ช่อง Normal / Magic / Rare เลือก
  S / A / B / C / D เริ่มที่ B ทุกช่อง) · select ที่หัวกลุ่มตั้งทุก class ในกลุ่มพร้อมกัน (เลือก S/A/B/C/D = ทุกแถวเป็น
  "ตั้งค่าเอง" ด้วยค่านั้น · "ค่าเริ่มต้น" = ทุกแถวในกลุ่มกลับเป็นค่าเริ่มต้น)
  ช่องที่ตั้งชนะทุกชิ้นของ class+rarity นั้น **รวมของดีที่ NeverSink จัดไว้ด้วย** — ตั้ง D = ซ่อนทั้งหมด
  Unique ไปตั้งที่หมวด Unique · Flask / Charm / Tincture มีหมวดของตัวเอง

**กุญแจ/ของพิเศษ และ Gem ทั่วไป** ไม่มีให้ตั้งในแท็บนี้ — ไฟล์ใช้ block ของ NeverSink ระดับ 2
ตามที่ NeverSink เขียนทุกอย่าง (เงื่อนไข สี ขนาด ไอคอน ลำแสง เสียง รวม Show/Hide) เหมือนแท็บ NeverSink
block เหล่านี้ใช้เสียงของ NeverSink ตามเดิม (เสียง 1 – 6 ของแท็บ NeverSink ไม่มีผลในไฟล์ Whitelist)

**แท็บย่อย** — [ไอเท็ม / หมวด] [Gold] [Map / Waystone] [Tablet (PoE2)] [Gem] [พิมพ์เอง]
แต่ละแท็บย่อยมีตัวตั้งค่าของตัวเองและ **สไตล์ของตัวเอง (สี ความทึบ ขนาด ไอคอน ลำแสง เสียง) แสดงในหน้าเลย**
- **Gold** — ติ๊ก = โชว์เมื่อจำนวน ≥ N (น้อยกว่าซ่อน) · ไม่ติ๊ก = โชว์ตามเกม
- **Map / Waystone** — โชว์เมื่อ tier ≥ N และ rarity ≥ ที่เลือก (ไม่ติ๊ก = โชว์ตามเกม)
- **Tablet** (PoE2) — สไตล์ของ Tablet ที่ไม่ได้ตั้ง tier รายชิ้น
- **Gem** (PoE2: Uncut Skill / Spirit / Support + level ขั้นต่ำ · PoE1: พิมพ์ชื่อ gem) — เลือก tier ของ Gem และปรับสไตล์เฉพาะ Gem ได้
- **พิมพ์เอง** — พิมพ์ชื่อ base (เช่น `heavy belt`) + เลือก rarity + tier

**จำนวนขั้นต่ำ (stack)** — ตั้ง "โชว์เมื่อจำนวน ≥ N" ต่อ tier (S / A / B / C) หรือต่อชิ้นได้
(ของที่ NeverSink โชว์เฉพาะตอนเป็นกอง จะใช้เกณฑ์ของ NeverSink เป็นค่าเริ่มต้น)

**สไตล์** — แก้สีตัวอักษร / กรอบ / พื้นหลัง ขนาด ไอคอน ลำแสง ได้ และตั้ง **ความทึบ** ของแต่ละสี
(255 = ทึบ, 0 = โปร่งใส) · ทุกสไตล์มีเสียงของตัวเอง

**เปิด filter เก่ามาแก้** — ปุ่ม **เปิด filter…** เปิดไฟล์ที่ **แท็บ Whitelist ของโปรแกรมนี้** สร้างไว้ได้
(ค่าที่ตั้งฝังอยู่ในไฟล์ท้ายไฟล์ เป็นบรรทัด comment ที่เกมไม่สนใจ) ชื่อ filter จะตามชื่อไฟล์ที่เปิด
แก้แล้วกด Generate เพื่อเขียนทับไฟล์นั้น (โปรแกรมถามก่อนทับ)
ไฟล์จากรุ่นเก่าที่ยังไม่มีค่าฝังก็เปิดได้ — โปรแกรมอ่านกลับจาก block แล้วบอกใน Status ว่าส่วนไหนเดา
ไฟล์ที่ไม่ได้สร้างจากโปรแกรมนี้ หรือสร้างจากแท็บ NeverSink เปิดแก้ไม่ได้

## แก้ปัญหา

**Generate แล้วขึ้น error เขียนไฟล์ไม่ได้ (เช่น `[Errno 9]` / Bad file descriptor)**
สาเหตุที่พบบ่อยคือ **Windows Defender "Controlled Folder Access"** (ระบบกัน ransomware)
บล็อกไม่ให้โปรแกรมหน้าใหม่เขียนไฟล์ลงโฟลเดอร์ Documents / My Games วิธีแก้:
1. Windows Security → **Virus & threat protection** → **Ransomware protection** →
   **Controlled folder access** → **Allow an app through Controlled folder access** →
   เพิ่ม `PoE-Filter-Generator.exe`
2. หรือกด **Browse...** ที่ช่อง *Game folder override* ในโปรแกรม แล้วเลือกโฟลเดอร์
   filter ของเกมเอง (โฟลเดอร์ที่ไม่ถูกบล็อก)

> ค่าเริ่มต้นของ Windows คือ "ปิด" CFA — ส่วนใหญ่จะไม่เจอปัญหานี้ แต่ถ้าคุณเปิดไว้ ใช้วิธีด้านบน
